# ⛳ ゴルフ組合せ

社内ゴルフコンペの組合せを作り、案内状を印刷するためのブラウザアプリです。
インターネット接続は不要です。入力したデータは外部に送信されません。

## 起動

- 公開版：https://shar19-ops.github.io/keiba-baren/golf-pairing/
- 簡易取説：https://shar19-ops.github.io/keiba-baren/golf-pairing/manual.html（アプリ右上の「使い方」からも開けます）

`index.html` をダブルクリックしても、ブラウザ（Edge / Chrome）で開けます。
人に配るときは、`golf-pairing` フォルダを丸ごと渡してください（`index.html`・`core.js`・`app.js` の3つがあれば動きます。取説も付けるなら `manual.html` と `manual-images/` も）。

初めて開いたとき（保存データが無いとき）は、架空の参加者14人と大会情報のダミーデータが入っています。①参加者の「全員削除」と案内状の入力欄の書き換えで、自分のデータに置き換えてください。
URL の末尾に `#pairing`・`#invitation`・`#history` を付けると、そのタブを開いた状態で表示されます。

取説の画面写真（`manual-images/`）は、動作確認用サーバー（`node tests/dev-server.js`）を起動し、ヘッドレス Edge で `http://localhost:8766/#players` などを幅 1100px で撮ったものです。

## 使い方

1. **① 参加者**
   Excel で「氏名」と「HC」の2列を選んでコピーし、枠に貼り付けて「置き換えて取り込む」を押します。
   - HC は空欄でも構いません。1行目が見出し（氏名・HC など）の場合は、自動で読み飛ばします。
   - 読み込めない HC や重複した氏名があると、行番号付きで表示します。
   - 取り込んだ後でも、表の中で直接修正・削除・追加ができます。
2. **② 組合せ**
   - 組数は人数から自動で決まります。4人組が基本で、端数が出たら後ろの組を3人組にします（例：14人なら 4・4・3・3）。
   - コースを「OUTとINに分ける」にした場合は、OUT・IN それぞれの最後の組を3人組にします（例：14人なら OUT 4・3 ／ IN 4・3）。3人組が奇数なら、余りは IN 側に回します。
   - 各組の「先頭」を選び、割振り方式を選んでから「自動割振り」を押すと、残りのメンバーが割り振られます。
     - **HC均等**：各組の HC 平均がそろうようにします（HC が無い人は全体の平均として扱います）
     - **ランダム**
     - **HC順**：HC の近い人同士を同じ組にします（HC が無い人は最後の組）
   - もう一度「自動割振り」を押すと、別の組合せになります。先頭と 📌 固定の人は動きません。
   - メンバーを1人クリックし、次に別の組のメンバー（または空き枠）をクリックすると入れ替わります。入れ替えた人には自動で 📌 が付きます。
   - 開始時刻・スタート間隔・コース（全組OUT / 全組IN / OUTとINに分ける）から、各組のスタート時刻を計算します。
   - 「直近3回と同じ組をなるべく避ける」（初期値はオン）：④履歴に保存した直近3回の大会で同じ組だった2人を、なるべく別の組にします（重みは 前回3・2回前2・3回前1）。同組の重みの合計を最優先で減らし、同じなら割振り方式のそろい具合で比べます。前回などと同じ組の人には 🔁 が付きます。
3. **③ 案内状**
   - 「雄J会 組合せ表」と同じ書式です。表題・回数（6/8回 など）・日付・集合時刻・ゴルフ場・TEL・FAX を入力すると、下にプレビューが出ます。
   - 組合せ表はコースごとに「OUTスタート 8:14（敬称略）」の見出しが付き、列は 1枠〜4枠（OUT・IN に分けたときの IN は 5枠〜8枠）、各枠は上に HC・下に氏名（均等割付）です。各コースに2組以上あり、スタート間隔が0分でなければ、組番号の下に各組の時刻を小さく出します。
   - 連絡事項は任意で、入力したときだけ TEL・FAX と組合せ表の間に出ます。会費・幹事も任意で、入力したときだけ表の下に出ます。
   - 「QR コードを載せる」：「画像を選ぶ」で QR コードの画像（例：リポジトリ直下の `馬券投票アプリ読取用.png`）を選ぶか、コピーした画像を案内状タブで Ctrl+V すると、表の右下に説明文付きで載ります。PNG・JPEG・GIF・WebP の 1MB までの画像に対応しており、画像は保存データ（JSON 書き出しにも）に含まれます。
   - 「トトカルチョ投票券を付ける」にチェックすると、キリトリ線から下に投票券（○—○、氏名欄）が付きます。文言と ○—○ の数は変えられます。
   - 「印刷 / PDF 保存」：案内状だけを A4 で印刷します。PDF にしたいときは、印刷先に「PDF に保存」を選んでください。
   - 「組合せ表をコピー」：既存の Word や Excel の案内状に、表をそのまま貼り付けられます。
   - 「履歴に保存」：④履歴と同じです。
4. **④ 履歴**
   - 「履歴に保存」で、今の組合せを案内状の開催日・表題で記録します（氏名で記録。同じ開催日があれば置き換え）。
   - 案内状の開催日と同じ日付の履歴は今回の大会とみなし、避ける対象に入れません。対象は残りのうち日付の新しい順に3回です。
   - 一覧の「使う」のチェックを外した回（別のコンペなど）は避ける対象に入れません。直近3回はチェックした回の中から数えます。保存した回は最初はチェック付きです。
   - 一覧で各回の扱い（前回として避ける / 使わない / 今回の大会 / 対象外）と組合せを確認・削除できます。

## データの保存

- 入力した内容は、自動でこのブラウザ（localStorage）に保存されます。
- 別のパソコンに移したいときやバックアップを取りたいときは、右上の「JSON 書き出し」でファイルに保存し、移した先で「JSON 読み込み」を使ってください。
- ブラウザの閲覧データを削除すると、保存した内容も消えます。大事な大会の前には JSON 書き出しをしておくと安心です。

## 開発

```
npm test                      # core.js のテスト（Node 18 以上）
node tests/dev-server.js      # 動作確認用の簡易サーバー http://localhost:8766
```

- `core.js`：画面に依存しない処理（取り込み・組数計算・割振り・履歴・時刻・表の出力）。テストはこのファイルが対象です。
  - 履歴を使う割振り：今までの方式で作った案（2回目以降はランダムな案）から、先頭・固定以外のメンバーを組の間で入れ替えて点数が良くなる限り続ける山登り法を20回試し、いちばん良い案を採ります（40人で 0.3 秒ほど）。
- `app.js`：画面の表示・操作・保存
- `index.html`：画面の骨組みとスタイル（印刷用のスタイルも含む）
